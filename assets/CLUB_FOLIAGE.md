# Club foliage

`club-foliage.png` is a 1254 × 1254 RGBA image generated for this project with the built-in image-generation tool on 2026-09-12. It is an isolated leaf cluster with genuine transparent margins and gaps, used on instanced 3D canopy cards. It is not a full-scene background.

Art brief: individually readable broad deciduous leaves; rich dark forest greens and olive greens; subtle warm sunlight; front-facing orthographic isolated cluster; no trunk, pot, text or ground; transparent outside and leaf gaps. The runtime retains the old canopy if the texture fails to load, and only the opt-in rigged court requests it.
